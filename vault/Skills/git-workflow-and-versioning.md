## 💡 Para que Serve

Estrutura práticas de fluxo de trabalho git. Use ao fazer qualquer alteração no código. Use ao confirmar, ramificar, resolver conflitos, dividir o trabalho não confirmado em uma árvore de trabalho confusa em confirmações atômicas limpas, abrir ou revisar uma solicitação pull (PR), enviar para um controle remoto ou quando precisar organizar o trabalho em vários fluxos paralelos. Use ao cortar um lançamento, escolher um aumento de versão semântica, marcar ou escrever um changelog. Use quando solicitado a escrever uma mensagem de commit ou uma entrada de changelog para uma mudança, ou para dividir uma mudança em commits, mesmo quando o diff é colado in-line e a mensagem parece fácil de escrever a partir dele.
