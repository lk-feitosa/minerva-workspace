## 💡 Para que Serve

Use o MagicPath por meio da CLI magicpath-ai para localizar, visualizar, inspecionar, instalar, exportar, criar e editar componentes de UI e gerenciar habilidades do MagicPath. Gatilho para projetos/componentes MagicPath; projetos pessoais ou de equipe; telas ativas e componentes/imagens/revisões selecionados; temas/sistemas de design; equipes, membros, propriedade, atribuição, auditorias de componentes instalados e links de compartilhamento/visualização. Use ao exportar componentes ou revisões exatas do MagicPath para pastas/aplicativos locais; substituir, adaptar ou traduzir a UI local com fidelidade 1:1 e alterações explícitas solicitadas; instalar componentes React/TypeScript com inspecionar/adicionar; criação de componentes de tela interativos responsivos com início/envio de código; importar ou recriar UI de caminhos locais ou repositórios GitHub/GitLab/Bitbucket para MagicPath; ou criar, recuperar, atualizar, importar, ativar, desativar ou excluir habilidades do MagicPath. Em hosts com um navegador incorporado, mantenha a tela do projeto aberta por meio de URLs de compartilhamento para trabalho visual.
