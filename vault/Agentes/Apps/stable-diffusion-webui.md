# Aplicação: Stable Diffusion WebUI (AUTOMATIC1111)

> [!INFO] **Visão Geral**
> **Repositório Oficial:** [https://github.com/AUTOMATIC1111/stable-diffusion-webui](https://github.com/AUTOMATIC1111/stable-diffusion-webui)  
> **Caminho Local no Disco:** `S:\DEV\apps\stable-diffusion-webui`  
> **Aceleração Local:** GPU dedicada (NVIDIA / Apple Silicon / AMD) ou CPU

### Descrição
Interface gráfica completa para geração local de imagens via difusão latente, com suporte acelerado por hardware com aceleração de GPU local (NVIDIA CUDA / Apple Silicon MPS / CPU).

---

### Como Executar
Execute `webui-user.bat` na pasta `S:\DEV\apps\stable-diffusion-webui` para iniciar o servidor web local em `http://127.0.0.1:7860`.
