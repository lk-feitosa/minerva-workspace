## 💡 Para que Serve

Maior biblioteca open-source de componentes animados e interativos para **React & Next.js** (text animations, backgrounds, cards, micro-interações em `TS/JS` com `CSS` ou `Tailwind`). Para que os agentes busquem e instalem componentes do React Bits no projeto atual, use a skill [[Skills/shadcn|shadcn]] com o registry configurado em `components.json`:

```json
{
  "registries": {
    "@react-bits": "https://reactbits.dev/r/{name}.json"
  }
}
```

Exemplo direto via CLI: `npx shadcn@latest add @react-bits/SplitText-TS-TW`
