# Suíte de Skills: `emilkowalski/skills` (Design Engineering & Motion)

> [!INFO] **Metadados da Suíte**
> - **Origem:** [`emilkowalski/skills`](https://github.com/emilkowalski/skills) (Emil Kowalski)
> - **Instalação global (`skills.sh`):** `npx -y skills add emilkowalski/skills -s "*" -g -y`
> - **Categoria:** [[Skills/🎨 Design, UI & Frontend Systems|🎨 Design, UI & Frontend Systems]]
> - **Total de skills no pacote:** `20` skills focadas em design engineering, animações web/mobile, gestos, performance de motion, Sonner e Swift moderno.

---

## Quando Usar

Acione o roteador `ask-emil` para escolher a skill exata da suíte, ou chame diretamente conforme a necessidade:

- **DAILY (recomendadas para projetos Frontend no `agent_sort.py`):** `emil-design-eng`, `animate`, `review-animations`, `animation-performance`, `mobile-native`.
- **LIBRARY (on-demand):** demais 15 skills especializadas em coreografia, gestos, auditoria, Expo, Apple Design, Sonner, stress-test de UI e Swift 6.

## Catálogo Completo (20 Skills)

| Skill | Finalidade Principal |
| :--- | :--- |
| `emil-design-eng` | Filosofia de design engineering para polish de UI, micro-interações, hover/press states, popovers, tooltips e detalhes invisíveis. |
| `animate` | Constrói animações web do zero decidindo propósito, ferramenta, propriedades, curvas, duração, interrupção e saída. |
| `animate-expo` | Constrói animações em React Native e Expo com Reanimated, Gesture Handler, Expo Router e `expo-haptics`. |
| `animation-performance` | Mantém animações no frame budget (propriedades composite-only, fora da main thread, diagnóstico de jank/GPU layers). |
| `animation-vocabulary` | Glossário reverso para dar nome exato a efeitos de motion a partir de descrições informais. |
| `apple-design` | Traduz princípios da Apple (WWDC) de motion físico, molas, gestos, profundidade e tipografia para a web. |
| `ask-emil` | Roteador interativo que recomenda a skill ou sequência certa dentro da suíte `emilkowalski/skills`. |
| `ask-sonner` | Guia completo para instalar, estilizar, tematizar e depurar toasts com Sonner no React. |
| `break-ui` | Stress-test de UI com dados extremos (nomes longos, listas vazias, emojis, números gigantes) com toggle *Worst Case*. |
| `choreograph` | Coordena múltiplos elementos animados juntos (stagger, sequência, crossfade, `AnimatePresence`, hero entrances). |
| `find-animation-opportunities` | Auditoria read-only que identifica onde a UI deve ganhar motion e rejeita animações desnecessárias. |
| `gestures` | Interações de drag, swipe, fling, sheets e Vaul que acompanham o dedo 1:1 e permanecem interrompíveis. |
| `improve-animations` | Auditoria de codebase de motion que gera planos priorizados de melhoria sem editar o código diretamente. |
| `learn-taste` | Converte correções de design feitas na sessão em regras permanentes (`DESIGN.md`, skill ou lint). |
| `mobile-native` | Ajustes CSS e meta-tags para web apps/PWAs parecerem nativos no celular (`100vh`, sticky hover, notch, tap lag). |
| `pick-ui-library` | Seleciona a biblioteca ideal de frontend (primitivos, toasts, drawers, command menus, charts, drag-and-drop). |
| `prototype` | Gera múltiplas variantes visuais distintas de um componente atrás de um seletor live para comparar e promover. |
| `remove-animations` | Remove animações desnecessárias ou excessivas (ações de teclado, superfícies de alta frequência, decoração sem propósito). |
| `review-animations` | Revisa diffs e código de animação com barra alta de craft baseada na filosofia de Emil Kowalski. |
| `write-swift` | Escrita e revisão de Swift moderno (Swift 6 concurrency, value types, actors, protocolos, Swift Testing). |
