## 💡 Para que Serve

Simplifica o código para maior clareza. Use ao refatorar o código para maior clareza sem alterar o comportamento. Use quando o código funciona, mas é mais difícil de ler, manter ou estender do que deveria. Use ao revisar código que acumulou complexidade desnecessária. Use quando solicitado para simplificar, limpar ou reduzir o aninhamento de uma função ou módulo que já funciona, mesmo quando o código é colado in-line e nada mais precisa ser alterado.
