# Framework: Kan (Open-Source Kanban & MCP)

> [!INFO] **Visão Geral**
> **Repositório Oficial:** [https://github.com/kanbn/kan](https://github.com/kanbn/kan)  
> **Caminho Local no Disco:** `S:\DEV\frameworks\kan`

### Descrição
Quadro Kanban moderno e auto-hospedável com suporte nativo ao protocolo MCP (@kan.bn/mcp) para orquestração visual e autônoma de tarefas no Maestri Canvas.

---

### Como Utilizar em Projetos
Suba via Docker (`docker compose up -d` em `S:\DEV\frameworks\kan`) e visualize via nó de Portal no Maestri Canvas (`maestri portal create http://localhost:3000`).
