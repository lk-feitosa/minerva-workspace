## 💡 Para que Serve

Impulsiona o desenvolvimento com testes usando o loop red-green-refactor. Use ao implementar qualquer lógica, corrigir qualquer bug ou alterar qualquer comportamento. Use quando precisar provar que o código funciona, quando chegar um relatório de bug ou quando você estiver prestes a modificar uma funcionalidade existente. Use quando for solicitado a adicionar testes a uma função, corrigir um bug ou alterar seu comportamento, mesmo quando o código for colado in-line e a solicitação não mencionar testes.
