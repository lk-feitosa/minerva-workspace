## 💡 Para que Serve

Opera aplicativos desktop no macOS, Windows e Linux diretamente pela árvore de acessibilidade nativa do sistema operacional usando a CLI agent-desktop. Use quando um agente de IA precisar observar ou agir em interfaces gráficas (clicar botões, preencher formulários, ler estado da UI, navegar menus, marcar caixas, rolar, arrastar, digitar texto, usar atalhos, capturar telas, gerenciar janelas, área de transferência, abrir/fechar apps e ler notificações).
