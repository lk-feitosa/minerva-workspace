## 💡 Para que Serve

Inspecione as verificações de PR do GitHub com gh, extraia logs de ações do GitHub com falha, resuma o contexto da falha e, em seguida, crie um plano de correção e implemente após a aprovação do usuário. Use quando um usuário solicitar para depurar ou corrigir falhas nas verificações de CI/CD de PR nas ações do GitHub e desejar um plano + alterações de código; para verificações externas (por exemplo, Buildkite), relate apenas o URL de detalhes e marque-os fora do escopo.
