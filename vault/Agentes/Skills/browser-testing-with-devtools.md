## 💡 Para que Serve

Testes em navegadores reais via Chrome DevTools MCP. Use ao criar ou depurar qualquer coisa que seja executada em um navegador. Use quando precisar inspecionar o DOM, capturar erros do console, analisar solicitações de rede, criar perfil de desempenho ou verificar a saída visual com dados reais de tempo de execução. Requer que o servidor MCP chrome-devtools seja configurado.
