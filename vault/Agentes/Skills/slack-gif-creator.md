## 💡 Para que Serve

Kit de ferramentas para criação de GIFs animados otimizados para Slack, com validadores para restrições de tamanho e primitivas de animação que podem ser compostas. Essa habilidade se aplica quando os usuários solicitam GIFs animados ou animações de emoji para o Slack a partir de descrições como "faça para mim um GIF para o Slack de X fazendo Y".
