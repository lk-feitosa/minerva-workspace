# Aplicação: Unsloth (Fine-Tuning de LLMs)

> [!INFO] **Visão Geral**
> **Repositório Oficial:** [https://github.com/unslothai/unsloth](https://github.com/unslothai/unsloth)  
> **Caminho Local no Disco:** `S:\DEV\apps\unsloth`  
> **Aceleração Local:** GPU dedicada (NVIDIA / Apple Silicon / AMD) ou CPU

### Descrição
Engine de fine-tuning e inferência ultra-rápida (5x mais rápida com 80% menos VRAM) para Llama-3, Mistral, Gemma, Phi e Qwen na GPU.

---

### Como Executar
Use com `uv` ou `python` a partir de `S:\DEV\apps\unsloth` para calibrar ou treinar modelos locais sob medida.
